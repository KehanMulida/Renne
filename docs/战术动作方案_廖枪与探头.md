# 战术动作方案：廖枪/匍匐（卧姿）与探头（Peek）

> 状态：设计评审稿 v2（**暂不写代码**，先定方案与操作逻辑）
> 关联：延续下蹲姿态系统；Sanity 影响待后续横向设计
> 日期：2026-07-26

---

## 1. 背景与目标

延续已实现的**下蹲**（可逆姿态 + 真扣 AP），继续把潜行战术动作做完整。本轮设计：

- **廖枪 / 匍匐（卧姿）**：卧倒姿态。以**组合键**触发——按住即卧姿，期间可稳射（廖枪）或爬行（匍匐）。
- **探头 (Peek)**：贴墙角后用最小暴露换取观察/射击角度。

设计遵循**偷袭三角**：每个动作是花代价在 **视野 / 声音 / 位置** 三轴上做取舍。

---

## 2. 姿态三态机（地基改动）

现有 `PlayerController._isCrouching`(bool) 升级为离散枚举：

```
enum Stance { Stand, Crouch, Prone }
```

| 姿态 | 移动 | 声音倍率 | 检测点高度 | 射击散布 | 备注 |
|---|---|---|---|---|---|
| 站立 Stand | 正常 | 1.0 | 1.0 | ×1.0 | |
| 下蹲 Crouch | ×0.6 | 0.3 | 0.4 | ×0.7 | 已实现 |
| 卧倒 Prone | **爬行上限 1 格/回合** | ≈0（极静） | 0.15 | ×0.35（最稳） | 组合键触发 |

- 复用下蹲框架：`RefreshAP` / `OnMoveMultiplierChanged`(可扩为 `OnStanceChanged`) / `IDetectable.DetectionPosition` / `SoundEmitter` 联动。
- 卧姿**不锁死移动**：本回合可爬行一小段（`ProneCrawlRange`，默认 1 格，可调），极慢极静；射击照常。
- **不需要拆分 AP 池**：卧姿只是把可移动范围**上限**压到 `ProneCrawlRange`（显示层只画这么多可达格），射击/换弹照常扣现有 AP。

## 3. 整体按键方案

点击式战棋：鼠标管移动+执行，键盘管姿态/战术。**现有键位全部不动**，仅新增。

```
 ┌── 姿态 ──┐      ┌──── 战术 ────┐        ┌─ 系统 ─┐
   C  站 ⇄ 蹲        V   探头(长按)           Tab 背包
   Ctrl 匍匐(长按)                            Esc 取消
        └─ 组合键：按住期间↓                   Space 结束回合
           LMB = 廖枪稳射
           RMB 点邻格 = 爬行(≤1格)
           松开 = 起身

 ┌──────── 交互/物品 ────────┐
   E 交互/换层   Q 拾取   R 径向菜单   F 换弹   滚轮 切槽

 ┌──────── 鼠标 ────────┐
   LMB 执行当前模式(射击/投掷/近战/使用)   RMB 点地移动   滚轮 切槽
```

**本轮实际新增**：`Ctrl`(匍匐修饰键，长按)、`V`(探头，长按)。`C` 保持下蹲不变。**不再预留 X/G/Shift**。

> `Ctrl` 为暂定键，理由：与鼠标瞄准形成"稳住/放低"手感的左手 chord，不与现有键冲突。若手感不好可换（如长按 C）。

## 4. 墙角判定（掩体/探头几何规则）

不依赖 `CoverConfig`，纯用 `GridManager` 的可走/阻挡数据。玩家在格 `P`、楼层 `F`：

1. **贴掩体（自动进入 InCover）**：4 邻格存在**阻挡格** `W`（墙/障碍/scene item）→ 自动进入 `InCover`，`W` 挡住来自其背后方向的敌人视线（隐蔽增益，反映到 `IDetectable` 被侦测判定）。
2. **墙角开口（探头方向）**：掩体在玩家 `d` 方向。对垂直两侧 `s`(±perp)：
   - `P+s` 可走（能侧身探入）**且** `(P+d)+s` 可走（墙那侧过去开阔、能获视线）⇒ **该侧存在可探墙角**。
3. 一面墙左右两角可能都能探、也可能只有一个。

```
   ■=掩体(阻挡)  P=玩家  ↖=可探墙角开口
   . ↖ . .        向北: P北空、墙北空 → 可向北探头看东侧
   P  ■ .
   .  ■ .         向南: 墙向南延伸 → 南侧不可探
```

> 只做**侧向绕角探头**。越顶探头（趴矮掩体上探）需每格掩体高度数据，网格暂无，列为后续。

## 5. 动作 A：廖枪 / 匍匐（卧姿组合键）

**定位**：卧倒姿态。极致压低"位置轴"（爬行、最难被发现）换稳射与隐蔽。用已预留的**低位 FirePoint**。

**三轴取舍**：`−移动(仅爬1格)` · `−−被检测(0.15)` · `++射击精度(散布×0.35)`

**核心：组合键（chord）——按住 `Ctrl` 即卧姿**，期间：
- **LMB = 廖枪稳射**：`ShootWeapon` 用低 FirePoint + 散布 ×0.35（架枪最稳）。
- **RMB 点相邻格 = 匍匐爬行**：移动 ≤ `ProneCrawlRange`(默认 1) 格，极慢极静，仍保持卧姿。
- **松开 `Ctrl` = 起身**（回到之前的 Stand/Crouch）。

**操作逻辑**：
```
按住 Ctrl（前提：非乘坐、非仓库开）
  → Stance = Prone
  → 切低位 FirePoint；播趴下动画；OnStanceChanged（视野/声音/检测点刷新）
  → 移动范围上限压到 ProneCrawlRange（显示层只画≤1格可达）
  期间 LMB → 廖枪稳射（散布×0.35）
  期间 RMB 邻格 → 爬行1格（扣移动AP，near-silent）
  敌人 QTE 来袭 → 卧姿只能爬1格躲或松开起身跑
松开 Ctrl → 起身 → 恢复 FirePoint/移动
```

**状态机**：`Stand/Crouch ──按住Ctrl──▶ Prone ──松开──▶ 回原姿态`（卧姿是"按住维持"的瞬时态，非独立 toggle）。

**边界**：卧姿禁用大部分场景交互（开门/推箱）；卧姿 + 乘坐互斥；爬行受 §2 移动上限约束。

> 备选（若"按住+多次点击"手感累）：改为 `Ctrl` **切换式**进入卧姿（再按退出），期间同样 LMB 稳射 / RMB 爬行。待手感测试后定。

## 6. 动作 B：探头 (Peek)

**定位**：位置轴 × 视野轴微操。贴墙角用最小暴露换观察/射击角度。

**三轴取舍**：`位置不动` · `视野临时打开(绕掩体)` · `被检测=暴露态` · `AP=免费微操`

**前置**：§4 墙角判定——玩家贴墙角、该侧有开口。

**操作逻辑**：
```
移动到贴墙角格 → 自动 InCover（隐蔽；掩体挡来向视线）
长按 V（前提：InCover、该侧有开口）
  → 墙角判定找可探侧；两侧都可时鼠标指向选侧
  → State = Peeking(dir)
  → PlayerVision 遮挡射线临时忽略该掩体(或起点移到探出点) ⇒ 看到墙另一侧
  → IDetectable 切"暴露"：AI 此刻能看到你
开火：LMB → ShootWeapon（从探出点绕掩体射击）
松开 V → 缩回 InCover（恢复遮挡与隐蔽）
```

**状态机**：`Normal →(贴墙角)→ InCover →(长按V)→ Peeking →(松开)→ InCover →(离开格)→ Normal`

**边界**：无开口方向不给探；探头中被击中走正常 `TakeDamage`；探头与卧姿互斥（`Ctrl` 与 `V` 不同时）。

## 7. 精神值(Sanity)——暂缓，留待横向设计

Sanity 之后会影响**很多角色动作与选择**（不止这两个战术动作），是一个横跨战斗/潜行/叙事的系统。因此本方案**不**把 Sanity 写成廖枪/探头的硬门槛。

- 现阶段：廖枪/探头**不设 Sanity 门槛**，先按纯操作实现。
- 预留接口：动作触发处保留一个"可用性判定"钩子，将来 Sanity 系统成型后再接入（低 Sanity → 手抖不能稳射/维持探头，或散布渐变惩罚）。
- 关联既定方向"精神值低时负面状态"（见 status-effect 计划），届时统一设计。

## 8. 实现影响（本轮不写代码，仅列改动面）

| 系统/文件 | 需要的改动 |
|---|---|
| `PlayerController` | `_isCrouching`(bool) → `Stance` 枚举 + 参数查表；`ToggleCrouch` → `SetStance`；新增 `OnStanceChanged` |
| `PlayerConfig` | 下蹲那组倍率字段扩成**按姿态**表（含 Prone 档、`ProneCrawlRange`、姿态散布修正） |
| `PlayerInputController` | 新增 `Ctrl`(匍匐组合键)、`V`(探头长按)；卧姿期间 LMB→稳射 / RMB→爬行(范围上限压到 `ProneCrawlRange`)；探头态驱动瞄准/开火；**顺手删第 923 行过时"W 键"注释** |
| `EquipmentManager` | 卧姿用低位 FirePoint；射击散布乘姿态修正 |
| `PlayerVision` / 遮挡 | 探头时临时忽略所贴掩体（或移动射线起点） |
| `IDetectable` / `VisionPerception` | 探头=暴露态；姿态检测点扩 Prone 档 |
| `GridManager`(只读) | 墙角判定用现有 `IsWalkable` 邻格查询 |
| `TurnBasedUnit` | **无需改动**——卧姿靠移动范围上限，不拆 AP 池、不锁 AP |
