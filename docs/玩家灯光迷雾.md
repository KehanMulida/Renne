# 玩家灯光迷雾

打开 `Assets/Scenes/Test.unity` 并进入 Play。主相机上的 `PlayerLightFog` 已绑定场景的 Player。

- 相机保留原始 45° 俯角、-15° 朝向，删除了遮挡时自动改变俯角和绕玩家移动的逻辑。
- 运行时关闭原有场景主照明、降低环境光和反射，并创建跟随玩家的冷蓝色实时点光源。
- 默认可见范围 9 米，视野灯改为高度 4.2 米、强度 10 的宽角向下聚光灯，减少近墙高光和头顶亮斑。角色使用独立的低强度补光，补光只照 Player 层。
- `Radius`、`Intensity`、`Light Height`、`Light Color`、`Darkness` 可在主相机的 Inspector 调整。
- 暗区使用低亮度蓝灰环境光，保留少量建筑轮廓；亮区依靠点光源的平滑距离衰减过渡。
- 主相机 `CameraOcclusionHandler` 对挡住角色的 URP/Lit 模型使用局部抖动透视，范围由 `Local Fade Radius` 控制。墙面其他区域和墙体投影保持不变，远离后恢复原材质。
- 带 `NoOcclusionFade` 的物体仍禁止淡出。没有碰撞器的导入网格补充使用包围盒检测，限制在角色附近和指定遮挡层内。
- `Cold Environment Guide Lights` 下有入口、洗手台和走廊三盏短范围冷色引导灯。`FogGuideLight` 标记使它们保留照明，换楼层后关闭灯光贡献；轻微亮度波动可以通过 `Flicker Amount` 调整。
- 默认关闭玩家模型的投影，避免近距离光源产生巨大自阴影；停用组件后会恢复原设置。
- URP 资源 `Assets/Render/URP_Renderer.asset` 已开启附加灯光阴影和软阴影。
- 原有 FogWar 对象保持停用。此效果不保留探索记录，也不改动 AI 的视野判定。

建筑暗区由照明呈现；敌人、掉落物与相关 UI 由下述可见性逻辑另外控制。环境灯可以提示空间方位，但不会自动揭示墙后敌人。低于光源的矮墙可能被光照越过，目标实体仍按玩家眼睛高度的遮挡判断。

## 2026-10-16：信息边界与辨识度

- 主相机新增 `PlayerSceneVisibility`：敌人、尸体和 WorldItem 掉落物按玩家位置、9 米范围、楼层高度差、实体遮挡判断。可见性检查不会因为场景灯或墙面透视而放宽。
- 使用 `Renderer.forceRenderingOff` 隐藏不可见实体，不改变 AI、碰撞和声音；停用后恢复原值。敌人血条、附近拾取、搜刮菜单及场景交互使用同一判断。
- 没有 Collider 的大型墙面以渲染包围盒补充检查，结果偏保守；包含复杂门洞的合并网格建议拆分或提供准确碰撞器。
- 墙后对白仍可通过原偷听机制听到，但飘字移到玩家附近的声音方位，不跟踪隐藏角色的精确位置。
- `PlayerReadability` 提供哑光角色材质和贴地选中圈；角色两侧补光已按最新需求移除，仅保留正上方顶灯和室内基础环境光。近处最多显示一个青色拾取标记和一个琥珀色交互标记；纯装饰没有交互标记。
- 室内基础照明同时更新环境色和漫反射 SH，默认 `Indoor Fill=(0.28, 0.34, 0.43)`，主灯 `Shadow Strength=0.7`。背光地面和室内墙面保留细节，建筑轮廓可见，但不解锁墙后的敌人/物品。恢复停用前的环境光设置时也恢复 SH。
- 玩家 HP/SP 改为左下角显示，换层提示移到屏幕下方，减少身体附近遮挡。

## 玩家正上方相机锁定

- `Test` 主相机的 `IsometricCameraController > Lock Above Target` 已开启，默认高度为 `Offset.Y=6.5` 米。X/Z 每帧严格等于玩家位置，固定朝正下方看，不允许横向平移或剧情聚焦把机位拉到墙外。
- 相机上方有启用的障碍物时，通过球形检测和网格包围盒检测收低相机，并留出镜头与墙面的距离。玩家换位置后立即校正水平坐标；无障碍时平滑恢复高度。
- 已由楼层系统隐藏的上层模型不参与相机碰撞。层筛选使用 `Camera Obstacle Layers`；复杂合并网格仍建议有准确碰撞器。
- 顶灯在相机更新后执行，并每帧重置为世界坐标的垂直向下方向，避免父相机旋转带偏照明。

通过菜单 `Tools > Renne > Render Light Fog Preview` 生成前后对照和移动预览，输出在 `Artifacts/LightFog/`，不会保存临时场景修改。批处理也可执行 `-executeMethod PlayerLightFogPreview.Render`。
