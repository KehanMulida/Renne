# 卫生间相机（局部透明优先）

场景：Assets/Scenes/Test.unity。相机保持原来的偏移 (2,5.5,-4.8)、角度 (45,-15,0) 和 FOV。

本版停用 CameraWallDistance 和 RoomCameraDirector，隔间 Distance Scale 设为 1；靠近门、墙或进入试点隔间都不会触发自动缩放。黑色高遮挡层继续停用。

CameraOcclusionHandler 只对相机到角色的视线命中的遮挡开启角色附近局部切口，其他墙面保留，阴影继续遮光；支持 NoOcclusionFade 墙的局部切口。横向射线宽度由 0.4 缩至 0.15 米，局部半径 1.2 米，离开遮挡后保持 0.3 秒再恢复，减少门口闪动。切口采用清晰裁切，不使用点状透明。

修复 Trying to set shader on a Material Variant：不能先克隆变体再换 Shader。现在从目标局部透明 Shader 创建独立运行时材质，再复制原材质参数；离开遮挡恢复原共享材质，不修改项目源材质。

PlayerSceneVisibility 继续限制墙后的敌人、掉落物和 UI。本版尚未实现全地图建筑按房间裁剪，局部切口或低墙上方仍可能看到其他建筑细节。

验证记录：Artifacts/Visibility/room-validation.txt。验证真实 Material Variant 转换、颜色参数保留、源材质不变、恢复原材质，以及 200 次门边位置下距离/角度/FOV 不变。预览为 inside-stall.png 和 foreground-wall.png，均为已知场景位置，未反推用户截图的精确坐标。

补充修复：上层平楼板按网格实际世界高度分层，避免导入模型原点在地面导致楼板误归当前层；扫描时每个 Renderer 单独注册，避免父物体重复收录其他楼层的子网格。

## 移动结束后切换斜视/俯视

Main Camera 新增 MoveEndCameraView。保留斜俯视 (45,-15,0)，备用视角为角色正上方 6.5 米、垂直朝下，并保持相同方位角。切换耗时 0.55 秒。局部透明继续工作，CameraWallDistance 和旧 RoomCameraDirector 仍停用。

订阅玩家 UnitMovement.OnMoveComplete，一次完整路径完成后排队一次检测；移动中不检测，静止和镜头过渡只更新跟随/插值，不重新扫描遮挡。玩家初始化完成时另外做一次初始检查。敌人的移动不会触发。

从原斜视机位向角色身体的三个高度采样。至少两点被挡时切为俯视；俯视状态下三点全部畅通才恢复斜视；只有一个点擦墙时保留原状态，减少边缘切换。检测原斜视机位，避免切到俯视后因俯视本身畅通而立即切回。支持实体墙及无 Collider 的独立墙网格；后者仍采用保守包围盒。

测试：Artifacts/Visibility/move-end-view-validation.txt。使用真实 OnMoveComplete 事件验证移动中不检测、结束一次检测、遮挡切俯视、200 帧静止不重判、下一次结束恢复斜视。

## 2026-10-17：高模型整模型淡出

取消圆形切口。命中视线的遮挡模型使用标准透明材质，整个 Renderer 的所有材质统一淡出到 0.15，离开遮挡后恢复原共享材质。仍使用独立运行时材质，兼容 Material Variant。

按世界空间真实 Bounds 比较：模型自身高度必须超过玩家身高 0.05 米，且模型顶端超过玩家头顶 0.05 米。低柜、洗手台等半身遮挡，以及被抬高的矮模型排除。俯视切换的遮挡采样也排除这类矮物品；移动完成后才检测的规则保留。

整模型淡出以 Renderer 为单位，不自动隐藏整个场景父节点；一个 Renderer 若合并了多段墙，合并的墙会一起淡出。墙后的敌人和物品仍由 PlayerSceneVisibility 单独管理。

新增验证：Artifacts/Visibility/tall-model-fade-validation.txt。验证半身物体、无 Collider 矮物体、抬高矮物体排除，高墙包含，全模型 alpha 生效、无圆形窗口与源材质恢复。
