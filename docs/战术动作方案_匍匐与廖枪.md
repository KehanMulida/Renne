# 战术动作方案：匍匐（姿态）与廖枪（掩体盲射）

> 状态：**已实现**（对齐当前代码）。探头功能已移除。
> 日期：2026-07-27

---

## 1. 现状概述

在下蹲基础上完成了两个战术动作：

- **匍匐**：姿态系统的第三档（站 / 蹲 / 匍匐），`Z` 键切换。趴下爬行——最难被发现、最静、每回合限短距爬行。
- **廖枪（盲射）**：贴掩体时只把枪探出去盲射，人不露头——打不准但身体安全。`Ctrl` + `LMB`。

> **探头已移除**（原设计里"身体探出掩体精准射击"的动作），确认不需要，相关代码已删。

姿态另外接入了**姿态枪口高度**（下蹲/匍匐时枪口下沉）。

---

## 2. 姿态三态机

`PlayerController` 用 `enum Stance { Stand, Crouch, Prone }`，各档参数从 `PlayerConfig` 查表：

| 姿态 | 键 | 移动 | 声音倍率 | 检测点高度 | 枪口高度倍率 |
|---|---|---|---|---|---|
| 站立 Stand | — | 正常 | 1.0 | 1.0 | 1.0 |
| 下蹲 Crouch | `C` 切换 | ×0.6 | 0.3 | 0.4 | 0.55 |
| 匍匐 Prone | `Z` 切换 | 每回合限爬 `ProneCrawlRange`(默认1)格 | 0.1（最静） | 0.15（最低） | 0.2 |

- 姿态切换即时 `RefreshAP`（可逆、扣"已用"，不能刷步数）。
- 事件 `OnStanceChanged`：`SoundEmitter`（缩放噪音）、`PlayerInputController`（重画移动范围）订阅。
- `DetectionPosition` 随姿态降低 → 越低越难被 AI 视线命中。
- `FireHeightMultiplier`（姿态枪口高度）：下蹲/匍匐时开枪点下沉，供 `EquipmentManager` 用。

## 3. 按键总表（本系统相关）

| 键 | 动作 |
|---|---|
| `C` | 站立 ⇄ 下蹲 |
| `Z` | 站立 ⇄ 匍匐 |
| `Ctrl`（按住）+ `LMB` | 廖枪盲射（需贴掩体） |
| `LMB` / `RMB` / 滚轮 / … | 原有：执行/移动/切槽（不变） |

按键均为 `[SerializeField]`，可在 `PlayerInputController` Inspector 改。

---

## 4. 匍匐（Z）

**定位**：极限潜行姿态。压低位置轴换最强隐蔽。

**效果**：检测点 0.15、噪音 ×0.1、枪口下沉；**每回合总爬行 ≤ `ProneCrawlRange`（默认 1 格）**。

**移动上限实现**（`PlayerInputController`）：
- `_proneCrawlUsedThisTurn` 记录本回合已爬格数，**回合开始清零**。
- 显示范围 = `min(剩余AP, ProneCrawlRange − 已爬)`；点击移动同样按剩余预算校验，移动后累加。
- 修复了早期"显示 1 格但能连点爬多格"的问题——现在是整回合总量上限。

**AP**：匍匐移动倍率保持 1（AP 不减），移动靠上述爬行预算约束，射击/其它 AP 不受影响。

---

## 5. 廖枪 / 盲射（Ctrl + LMB）

**定位**：贴掩体只露枪盲射，人不露头。打不准但绝对安全。

**触发**：贴掩体（墙角判定）时**按住 `Ctrl`** → `EquipmentManager.BlindFireMode = true`；此时 `LMB` 开火即盲射。松开 `Ctrl` 关闭。

**效果**（`EquipmentManager`）：
- 枪口沿瞄准方向**前伸** `blindFirePoke`(0.7)，越过掩体再出膛（避免打到自己的掩体）。
- 叠加**大范围随机散布** `blindFireAngle`(±20°)——朝鼠标方向乱打，无论武器多准。
- **不改 `DetectionPosition`**：人没露头，敌人看不到你（身体安全）。

**墙角判定**（`CoverUtil.TryGetCover`）：纯网格几何，不依赖 `CoverConfig`——
- 某方向邻格不可走 → 该方向有掩体；
- 垂直侧满足"能侧身探入 且 墙那侧过去开阔" → 视为可用掩体角。
- 匍匐 / 乘坐 / 仓库开启时不可用。

> 限制：目前廖枪需要一个"墙角"（侧向开口）才判定为贴掩体。朝正前方矮掩体"越顶盲射"需要每格掩体高度数据，网格暂无，列为后续。

---

## 6. 探头（已移除）

原设计："身体探出掩体 → 精准射击/观察，但暴露"。经确认**不需要**，已删除全部相关代码（横移眼位、`peekKey`(V)、`PickSide` 等）。`CoverUtil` 的墙角判定保留给廖枪用。
