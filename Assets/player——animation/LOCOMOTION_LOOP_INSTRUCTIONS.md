# 行走、下蹲行走、匍匐循环修改指令

1. 以当前 Unity 动画资源为准。先备份三个循环；投掷、拾取、姿态过渡、材质、敌人速度和原 Blender 文件保持不变。
2. 检查首尾骨骼位置、旋转、曲线切线；将末帧接回首帧，并让接缝两侧的运动速度一致。修正范围以循环边界及必要的支撑肢体为限，保留侧身、手指、重心起伏等风格。
3. 按每格一个完整左右交替循环校准支撑点。检查行走／下蹲的脚掌、匍匐的手掌；在支撑期间减小相对地面的滑动，保持抬脚／抬手的恢复阶段，并限制肢体伸展，避免关节反折。
4. 继续采用当前的玩家速度和每格两步，跨格时连续传递剩余帧时间。停止和姿态转换应从匹配的静止姿势平滑衔接。
5. 验证首尾姿势及切线、整段骨骼有效性、支撑点滑动变化、连续跨格速度、每格两次脚步，以及移动后停止／切换姿态。
6. 保存修改、备份和验证报告，明确记录仍存在的限制。
